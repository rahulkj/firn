Storage & retention

FlagDefaultEffect
-data-dir./dataLogs + topics.json + quorum state. "" = in-memory dev mode (restart loses everything)
-segment-bytes0 (64 MiB)Max bytes per segment; rolls files so whole-segment retention can actually delete
-block-seal-interval0Seal active segment once it outlives this age even without size pressure (drives replication + firn_blocks_sealed_total)
-retention-ttl0Delete whole segments whose newest record is older (active segment never deleted)
-retention-max-bytes0Max bytes per partition; oldest whole segments deleted first
-retention-interval1mSweeper cadence (only with TTL or max-bytes set)

Below the retention horizon, fetch returns FailedPrecondition — deliberately, so group bookkeeping never sees silent holes. Offsets are never renumbered.

Internal topics

Six shared single-partition logs, replicated in clusters like user topics, never federated: __consumer_offsets (group commits, upsert-compacted), __queue_attempts (claim/DLQ counters, max-fold), __audit, __api_keys, __federation_peers, __federation_cursors. Writes are single-writer-fenced in cluster mode.

firn

The durable event broker. Streams and queues over one append-only log.
